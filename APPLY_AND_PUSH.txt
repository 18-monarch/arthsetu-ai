ARTHSETU PRODUCTION HOTFIX
==========================

This fixes:
1. Dashboard crash: Cannot read properties of undefined (reading 'toUpperCase')
2. Legacy questionnaire localStorage migration
3. Live questionnaire → ML full-assessment integration
4. Safer score UI during stale/incomplete browser state

Copy every folder from this patch into the matching paths of your existing
arthsetu-ai project and choose Replace.

Then run:

git add lib/questionnaire-store.ts lib/ml-client.ts components/ui/score-orbit.tsx components/app/dashboard-client.tsx app/api/submit-questionnaire/route.ts
git commit -m "Fix production auth flow state and dashboard ML results"
git push origin main

Vercel will deploy automatically.

NEON AUTH CONFIGURATION (not a code change)
-------------------------------------------
In Neon → Auth → Configuration → Domains / Trusted origins, add:

https://arthsetu-ai.vercel.app

Also add the redirect URI if Neon presents a redirect URI list:

https://arthsetu-ai.vercel.app/app/dashboard

Keep http://localhost:3000 for local development.

After the code deployment, hard refresh the website. The patch automatically
migrates the older stored score format, so clearing browser storage should not
normally be necessary.
